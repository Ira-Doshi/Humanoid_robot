Multi-Actuator Humanoid Robot with Wireless Control and Interactive Facial Display

This project focuses on the design, development, and integration of a functional humanoid robotic platform combining embedded systems, servo-based actuation, wireless communication, mechanical construction, and human-machine interaction.

The robot is designed with a humanoid body structure consisting of a head, torso, two arms, and two legs, with multiple actuated joints enabling controlled movement of the robotic limbs.

An ESP32-based control architecture forms the core of the system. The controller manages the robot's actuators and receives movement commands through wireless communication. The robot also incorporates an interactive LED-based facial display, allowing it to provide visual expressions and feedback during operation.

The project was developed as a hands-on exploration of embedded robotics and mechatronic system integration, with emphasis on coordinating multiple electromechanical subsystems into a single functional platform.

The primary objectives of the project were to:

- Design and construct a humanoid robotic structure.
- Implement multi-joint servo-based actuation.
- Develop an ESP32-based embedded control system.
- Implement wireless communication between the controller and robot.
- Coordinate multiple actuators for robotic movement.
- Develop an interactive programmable facial display.
- Integrate electronics, mechanical components, wiring, and power systems within a compact humanoid structure.
- Establish a foundation for future autonomous robotic capabilities.
